# MatApp

Et læringsprosjekt i Python og Streamlit som genererer ukesmenyer, lager handlelister og beregner anslått pris ut fra budsjett og matpreferanser. På sikt er målet å bruke KI til matplanlegging.

## Hva jeg har lært

- Å strukturere Python-kode i funksjoner og moduler.
- Å bruke lister og ordbøker til å filtrere oppskrifter, beregne mengder og sjekke budsjett.
- Å bygge et interaktivt grensesnitt med Streamlit og håndtere brukerens valg.
- Å lagre menyer og innstillinger i SQLite og teste logikken med pytest.

## Start appen

Med Python installert, åpne en terminal i prosjektmappen og kjør:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Åpne adressen som vises i terminalen (vanligvis http://localhost:8501). Stopp appen med `Ctrl+C`.
